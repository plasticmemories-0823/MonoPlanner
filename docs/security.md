# 安全与隐私

MonoPlanner 1.0 面向当前 Windows 用户的本机使用。不要将前后端端口映射到公网或局域网，也不要作为多人服务部署。

## 服务访问

前端只访问同源 `/api`，启动器指定固定回环后端。实例凭证用当前用户的 Windows DPAPI 保存，浏览器使用 HttpOnly、SameSite=Strict 会话 Cookie；凭证不放入 URL、浏览器本地存储或模型上下文。服务统一检查凭证、Host、Origin、JSON 请求类型及 8 MiB 请求大小。文档、指标、Studio、MCP、A2A、Webhook 和通用存储接口不对产品开放。

这些措施防止未经授权的网站直接控制本机服务，不防御已经控制当前 Windows 用户、浏览器或 Docker 的恶意程序。Cookie 随浏览器会话使用；关闭再打开界面时重新连接本地实例。

## 模型及记录

用户消息、为任务读取的源码和资料、工具结果、必要的历史及思考续接字段会发送给 DeepSeek。标题生成另发送首条公开用户消息；进度汇报发送最近已确认工作事实；联网搜索发送查询。详细请求、响应、思考、执行日志和源码快照保存在本机，用于追溯及恢复。这些记录可能包含用户代码、路径和业务数据，应按敏感资料管理。

DeepSeek API Key 由后端读取，当前用户 DPAPI 加密保存；环境变量和 `.env` 可作为后备。界面不返回已有密钥明文。密钥不写入请求归档，外部程序不继承服务凭证或模型密钥。移除资料授权无法撤回已经发送给模型或保存在历史中的内容。

## 执行与权限

编码、调查、验收和已有任务运行均要求 Docker。容器默认无网络、移除 Linux capabilities、禁止新增权限；不挂载助手密钥、控制接口或 Docker Socket。调查使用只读副本。Docker 或项目环境不可用时停止，不回退本机执行。镜像和用户项目必须可信；容器隔离不是绝对安全保证。

自动环境准备是单独的联网阶段。程序复制经过大小限制、敏感文件及链接检查的项目资料，在一次性安装容器中处理依赖；不传递 Windows 虚拟环境、本机凭据、助手密钥或可写项目挂载。安装容器只连接内部隔离网络，通过独立代理访问公网 HTTP/HTTPS 地址；代理拒绝私网、回环及保留地址，使用已校验的地址建立连接。准备依赖需要支持 isolated bridge gateway 的 Docker Engine（28 及以上），不支持时停止，不退回较弱隔离。

联网代理不能判断软件包是否恶意，也不能保证安装脚本不会向公网发送它能读取的项目资料；只应对可信项目和依赖执行准备。安装日志保存在本机，不自动发送给模型；排障时应先脱敏。项目依赖中的私有凭据不会从本机自动导入。

环境准备完成后，运行绑定固定镜像 ID；Node 依赖由程序创建的 Docker 数据卷只读提供。安装结果不允许在已有任务恢复时重新生成；丢失或不完整记录须保留现场。更换项目依赖配置只影响下一次尚未执行的任务，不能改变已经冻结的验收环境。

暂停通过独立控制通道取消模型并终止所属容器进程，不等待当前写操作结束。无法确认结果时保留现场，不自动重放或回滚；未确认容器停止时不会显示停止成功。正常退出仍核验活动任务与环境准备，不能因界面关闭而误判任务已经结束。准备容器和代理有执行时限；异常退出的未确认资源仍会保留。

基础环境首次构建使用专属 Docker BuildKit builder，不改变用户默认 builder；下载基础镜像需要 Docker 的正常网络连接。项目安装容器沿用上述受控下载网络。资源清理只针对已登记的确切资源及无引用副本，不执行 Docker 全局清理，不能清理用户项目或其他应用的容器。

额外资料按单文件或目录授权；单文件不扩大为父目录。路径检查拒绝链接、Windows 重解析点、备用数据流和敏感文件。沙盒权限禁止外部软件启动和目录外写入；风险询问使用绑定目标和原件的一次性批准；完全权限使本机文件操作和外部软件打开使用当前 Windows 用户权限，仍不将编码移出 Docker。

文件预览使用无脚本、无联网能力的隔离框架，内容不会自动发给模型。外部软件以普通用户权限运行，其自身写入不受编码容器限制。文件打开不能携带任意 Shell 或启动正文。

网页读取直接连接经验证的公网 IP，同时保留原域名用于 Host、TLS SNI 和证书检查。每次重定向重新核验，不使用环境代理重新解析目标。只读取有大小限制的文本，不执行网页脚本，不向站点发送模型密钥。

## 报告问题

在私有仓库中向维护者报告安全问题，提供版本、复现步骤和脱敏日志。不要将 API Key、完整用户任务记录或个人路径粘贴到公开 Issue。修复前停止使用受影响功能；不要通过关闭校验或改成管理员运行绕过错误。
