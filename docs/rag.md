# 统一检索

Chatbot 的 `retrieve_evidence` 与工作计划的 `op=search` 使用同一检索服务。检索只提供证据，不代替工作模型的判断或正式验收。容器资料的授权、路径和恢复规则见 [容器资料检索](container-rag-sources.md)。

## 检索模式

- `mode=exact` 是默认模式，按完整字符串、区分大小写进行字面匹配。空白、中文、标点与 `AND/OR` 保持原义。BM25 只排列真实命中，不改写查询，也不用 TopK 截掉后续命中。
- `mode=semantic` 必须显式选择，使用本地向量模型与重排模型。模型、索引或资源不可用时返回原因和不完整标记，不自动改用另一种搜索模式。
- 精确检索可读取已授权工作区、项目、额外资料及受控容器来源。语义索引只覆盖当前项目与当前任务资料；Chatbot 只能读取允许的公开记录投影。
- 查询不会自动扩大权限范围。定位已有源码、文档、日志和容器资料使用搜索；已知位置使用 `read`。Shell 继续用于编译、测试、编辑与运行诊断。

## 固定参数与查询改写

参数由源码中的 `RagConfig` 固定，任务及索引核验其指纹。

| 项目 | 当前值 |
| --- | ---: |
| 语义召回候选上限 | 100 |
| 重排候选上限 | 20 |
| 切块正文软目标 | 256 Token |
| 完整片段硬上限 | 512 Token |
| 相邻片段重叠上限 | 64 Token |
| 检索工具消息上限 | 8,192 个估算 Token |
| 条件改写排序差阈值 | 0.15 |

精确搜索不加载向量模型、不调用查询改写。语义搜索只有适用的必需证据缺口、重排无赢家、来源单一或时效信号才可触发一次短改写；一个用户请求中的多次检索共享一次额度。原查询、触发原因与结果分别归档，续页复用已记录查询。结果未知时停止，不自动重发。

## 原文、分页与完整性

`limit` 默认 80、上限 1,000；`offset` 按命中计数。返回预算不足时提供更少条目及 `next_cursor`。游标绑定查询、模式、来源版本与排序视图，来源变化后需要重新查询。

模型可见格式为 `monoplanner-search-view-v1`：

- `sources` 为每个来源版本保存路径和哈希。
- `results[].source` 引用来源，`hits[].result` 引用原文片段，索引从 0 开始。
- 行列从 1 开始；字符范围使用 Unicode 左闭右开区间。
- 正文逐字保留，同行多处命中、截断标记、来源身份与续查位置均保留。完整排序和执行信息记录在本地原件中。

搜索返回实际命中窗口或语义片段，不自动扩展整段父级函数、类或文档。需要上下文时显式补读。`scan_complete` 与当前页是否完整分别说明，语义召回不代表穷尽全部资料。

长行可按同版本 UTF-8 字节游标继续读取；部分行不视为已完整读取。`from_step` 校验来源版本，最多 5 个命中共享原有 50 KiB 读取预算。原件先归档，再执行展示去重与载荷卸载，已发送历史不被改写。

## 本地模型

使用 `resources/rag-models.example.json` 的固定清单准备模型目录中的 `models.json`，模型路径相对清单解析。通过 `MONOPLANER_RAG_MODELS` 指定该清单；可选 CPU 依赖固定在 `requirements-rag-local.txt`，应安装到独立目录。权重、凭据和本机依赖不进入源码仓库。

| 用途 | 模型 | 固定修订 |
| --- | --- | --- |
| Embedding | intfloat/multilingual-e5-small，INT8 ONNX | `614241f622f53c4eeff9890bdc4f31cfecc418b3` |
| 重排 | cross-encoder/mmarco-mMiniLMv2-L12-H384-v1，INT8 ONNX | `1427fd652930e4ba29e8149678df786c240d8825` |

文件、分词器及运行库身份按清单核验。新任务绑定清单与参数指纹，进行中的任务不会因环境变量改变而替换模型。没有配置本地模型时，精确搜索仍可运行，语义搜索明确报告不可用。

## 资源与验证边界

本地 RAG 的额外内存预算为 1 GiB：单模型 worker 上限 768 MiB，其余预留给父进程。精确索引保存来源元数据，按需读取正文；当前单次原件准入上限由共享预留推导为 7.5 MiB。超出时返回 `source_read_memory_budget`、路径、大小及未读取位置，不记成零命中。超大文件的流式精确搜索尚未实现，可显式分段读取。

语义切块使用固定分词器核算正文、来源头与必要特殊 Token；长查询无法装入重排窗口时拒绝该次重排，不静默截断。索引构建保留任务归属，暂停与退出可取消；删除前先确认所属工作已停止。

程序校验 `[evidence:<chunk_id>]` 的来源、版本、哈希与返回范围，但不自动证明引文支持模型结论。当前也不自动识别所有自然语言事实缺失引用的情况；未提供时间范围时，时效信号记为不适用。

离线接线和资源检查不等同于检索质量提升。实际编码评测见 [两轮评测总结](benchmarks/2026-10-20/README.md)，发布验证范围见 [本次更新记录](updates/2026-10-20.md)。
