# Chatbot 与工作独立执行，应用服务统一管理公开状态

此前框架运行记录、产品会话和任务检查点分别保存运行状态，浏览器还负责补启动和多来源消息合并。此次保留 LangGraph 库组织 Chatbot，但移除 Agent Server 的第二套调度，由应用服务保存持久输入和公开事件；工作任务独立执行，原件仍决定执行和验收事实。进度说明只读取已提交事实，不能回写工作上下文。
