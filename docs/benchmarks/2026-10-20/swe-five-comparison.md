## 评分修正与统计说明

Requests 的首次评分环境错误地禁止测试容器联网，导致依赖 `httpbin.org` 的 48 项检查发生 DNS 错误。修正仅涉及官方评分容器的网络配置；使用两组原有候选补丁、原有测试及镜像免费重评，未调用模型重新解题。两组最终均为目标检查 7/7、回归检查 112/112，原始错误评分记录继续留档。

- 输入 Token 包含缓存命中输入；每行均满足 **输入 = 命中 + 未命中**。输出 Token 已含思考 Token，不再重复收费。
- 缓存命中率 = 命中输入 ÷ 总输入；汇总使用 Token 加权结果，不取逐题百分比的算术平均。
- 低谷费用（人民币）=（命中输入 × 0.02 + 未命中输入 × 1 + 输出 × 4）÷ 1,000,000；高峰费用为低谷的 2 倍。两列均为统一单价下的费用等价估算，不是实际请求时段混合费用，也不是服务商实扣账单。
- 解题时长累计暂停前后有效解题时间，排除暂停等待、环境准备、补丁导出和官方评分。按原始秒数求和后四舍五入为 `时:分:秒`，因此显示行相加与汇总最多可能有秒级舍入差异。
- “首次”指每个顶层任务的第一笔请求，“后续”包括该任务内的继续调用及原生续接；首次请求命中不代表服务商冷缓存。未知用量请求只进入请求数，不进入已知 Token 与缓存率分母。
- 整题通过率仅按最终官方通过题数 ÷ 固定题数计算；部分检查通过、系统自身验收通过均不等于整题官方通过。
