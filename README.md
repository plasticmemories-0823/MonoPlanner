# MonoPlanner

在本机查询资料、运行已有项目任务、实现和验证代码的 AI 助手。你可以直接聊天，也可以选择项目，让它读取源码、运行已有脚本，或按编码流程提出修改并验证。

![MonoPlanner 工作界面](docs/assets/workspace.jpg)

## 能做什么

- **聊天与工作切换**：同一个输入框，普通聊天不需要工作目录。
- **开工资料**：明确开始编码后，先准备原始要求、公开讨论、仓库概览、README、测试配置及容器环境，再生成编码计划。聊天与编码分别保存请求上下文。
- **可见的执行过程**：读取、搜索、运行命令和验收都显示在聊天流中，思考记录可以展开查看。
- **紧凑的聊天界面**：思考和操作按对话轮次分组，默认折叠；展开后可再查看单步内容。输入框随文本增长，左侧对话栏可拖动调整宽度。
- **底部用量统计**：缓存命中率按已返回缓存用量的输入 Token 加权；上下文占用按最近一次主模型请求的输入与回复计算，等待回复时标为估算值。它不是累计 Token，无数据时显示“暂无数据”。
- **运行中补充要求**：发送新消息或点击暂停会主动中断当前模型回复；实际操作在最近的执行边界接入新要求，保留已经完成的操作。
- **可验证的交付**：先试跑并冻结验收，再执行修改；实际失败会反馈返工，文字回复不能替代验收通过。
- **连续执行**：任务在同一个运行对象中推进，每步仍保存记录并检查补充消息。同一调查计划的成功命令共用只读副本和容器，暂停、失败或计划结束后释放；真正恢复时重新核验历史、源码及容器。
- **本地准备**：等待模型时可准备只读调查副本；只有版本和完整性核验通过后才会使用。准备未完成时按原流程执行，不等待后台准备，也不提前运行命令。历史原文保持在本地，检查点复用原件引用。
- **可选联网**：搜索公开资料、读取网页，来源与操作过程保留在本地记录中。
- **资料查询**：查询工作目录和你选定的额外可读目录，普通读取不初始化编码验收。
- **已有任务运行**：运行项目已有脚本或声明的任务，记录真实结果；失败先报告，不擅自修改代码。

## 下载与启动

使用 Windows 11 x64 便携包：解压 ZIP，双击 **MonoPlanner.exe**。包内带有固定版本的 Python、Node.js、Git、生产前端及 WebView2 备用运行时，聊天、查询和预览不需要另装 Python、Node.js、pnpm；编码和已有脚本运行需要安装并启动 Docker，也不会在首次启动时安装依赖或构建前端。

首次使用，在输入框下方点击 **齿轮 → API Key 设置**，填写 DeepSeek API Key。模型请求和可选网页搜索需要网络并产生服务费用；仅打开应用不会调用模型。

用户项目自己的数据库、编译器、第三方库和正式评测镜像不包含在便携包内。缺少依赖或与沙盒不兼容时会明确报告，不会自动安装或解除隔离。

### 开发环境

| 组件 | 要求 |
|---|---|
| 操作系统 | Windows 11 x64，使用当前用户的 DPAPI 保存密钥 |
| 桌面运行时 | Windows 64 位、.NET Framework 4.8、Microsoft Edge WebView2 Runtime |
| Python | 推荐 3.13 |
| Node.js | 22 或更新版本 |
| 包管理器 | pnpm，项目声明版本 10.5.1 |
| 模型服务 | DeepSeek API Key；目前仅支持 DeepSeek Flash |
| Docker | 编码、调查、验收和已有脚本运行需要；聊天和查询不需要 |

在工作目录窗口展开 **执行环境 · Docker**，选择本机已有项目镜像，填写容器内 Python 路径和可选 Conda 环境并保存。默认路径是 `/opt/miniconda3/envs/testbed/bin/python`、Conda 环境 `testbed`；其他镜像填写实际 Python 路径，不用 Conda 时留空。仅支持 Linux amd64/Bash 镜像，不自动拉取镜像或安装项目依赖。环境未配置或 Docker 不可用时停止执行，普通聊天不受影响。

项目配置位于用户数据目录的 `project-environments.json`。首次执行前冻结镜像 ID、运行环境和挂载；后续配置只影响新任务。容器、原始记录或结果不明时不自动重建或重放。已有任务恢复使用对应冻结源码。

正式评测仍可通过 `MONOPLANER_EVALUATION_WORKSPACES` 配置固定目录与镜像 ID，格式为 `{"完整工作目录":"sha256:镜像ID"}`，沿用原 testbed 环境。它与普通项目使用同一编码与验收流程，不向模型提供官方答案或诊断。

上表适用于从源码开发。便携包已包含开发工具之外的运行依赖；Windows 自带的 .NET Framework 4.8 仍是桌面组件的系统条件。

## 快速开始

在项目根目录打开 PowerShell，安装后端和前端依赖：

```powershell
python -m venv .venv-web
.\.venv-web\Scripts\python.exe -m pip install -r requirements-web.txt
pnpm --dir web install --config.manage-package-manager-versions=false
pnpm --dir web build
```

首次构建桌面入口，运行 `scripts/build-launcher.ps1`；它会下载并核对固定版本的官方 WebView2 SDK，依赖仅放在 `launcher/runtime/`。系统需已安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

双击根目录的 **MonoPlanner.exe**，直接进入桌面 App，不打开浏览器，也不会自动发起模型任务。重复打开会显示已有 App 窗口；只有同项目、同版本且资源完整的服务才会复用。保持 EXE、`launcher/runtime/` 和项目文件在一起。

顶部 **MonoPlanner** 菜单提供“刷新界面”“重启服务”和“退出并停止服务”。关闭 App 也会停止服务。有运行中或排队任务时，重启和退出会被阻止：先在工作界面中暂停，并等待当前请求或操作结束。更新后发现旧服务时，仅在任务队列为空时替换旧服务。

需要浏览器访问时，也可以使用 [monoplanner.localhost:3000](http://monoplanner.localhost:3000/)，无需更改系统 hosts 或 DNS。原来的 IP 地址继续有效；App 与浏览器使用各自的界面偏好，但连接同一后端和任务记录。

首次使用，在输入框下方点击 **齿轮 → API Key 设置**，填写 DeepSeek API Key 并保存。密钥仅由本地后端读取，界面不会回显已有密钥。

如需分别启动前后端，在两个 PowerShell 窗口中运行：

```powershell
# 后端，默认端口 2024
.\scripts\start-server.ps1

# 前端，默认端口 3000
.\scripts\start-web.ps1
```

## 使用

### 开始一项工作

1. 点击输入框下方的文件夹按钮，打开目录选择窗口。
2. 浏览文件夹，或输入完整路径并点击“打开”，再点击“选择此目录”。
3. 需要运行项目时，展开“执行环境”，选择已有镜像并保存运行配置。
4. 描述目标和限制。助手默认先商讨细节、提出方案，信息充分后询问是否开工。
5. 明确同意开工，或直接说明“你直接动手”“按方案开始实现”，再在聊天流中查看调查、执行和验收结果。

例如：

> 请直接修改登录接口对空用户名的处理，保留现有错误响应格式，并补充回归测试。

“帮我做一个页面”等目标描述默认先讨论；选定目录不代表授权修改。讨论中可以展示完整代码，但不会因此创建文件或执行验收。已经授权的工作无需每一步重复确认；“先不改代码、只讨论、不要保存”等限制优先。

已经开始执行的任务不能中途换目录。需要更换项目时，请新建对话。

中途操作以阶段汇报显示。例如，原始源码试跑发现未通过项时，会提示接下来审查验收与修复方案；配置或加载问题则提示检查验收准备。可展开查看真实诊断，最终通过结论仍由修改后的实际验收决定。

### 模型、思考与联网

模型、思考程度、联网开关和设置位于发送按钮左侧。

| 设置 | 说明 |
|---|---|
| 模型 | DeepSeek Flash |
| 思考 | 关闭、low、high、max；默认 high |
| 联网 | 默认关闭；不影响正常 DeepSeek 模型连接 |
| API Key | 支持填写、替换和删除本机保存的密钥；留空保存保留已有密钥 |

这些选项保存为**新任务默认值**。当前任务及暂停恢复继续使用创建时的配置；设置窗口分别显示当前任务配置和新默认值。

网页搜索会额外调用 DeepSeek，并产生 Token 费用；读取网页不额外调用模型。网页内容只作为外部资料，不执行页面脚本，也不开放调查 Shell 的网络权限。原生搜索接口已完成离线回放，尚未经真实付费调用验证。

### 查询资料和运行已有任务

工作目录用于读取和任务运行。点击输入框下方的 **齿轮 → 额外可读资料**，可选择文件或文件夹并保存到当前对话。单文件只授权自身，不授权父目录；文件夹授权其中资料。查询、搜索、预览与沙盒资料副本使用相同授权。这些资料不能作为修改、执行或软件启动授权，运行期间须先暂停再变更。移除授权后，已经发送过的资料仍在历史中，不能撤回已发送给模型的内容。

可以描述“查看这个项目怎样运行测试”或“按项目说明运行现有测试”。遇到陌生名称，助手先查授权资料，缺少信息或出现多个候选时会询问；没有针对某道评测题的特殊规则。普通聊天不必先搜索。

已有任务可指定脚本、本地 Python 模块或 `package.json` 中声明的任务。运行发生在项目 Docker 容器中，使用容器的 Python、Node、Bash 或 PowerShell，不使用宿主机 `.venv`。只执行已有入口，不接受临时代码或 Shell 拼接正文；失败先报告，不自动转入源码修复，也不初始化编码验收。

需要 Windows 专有依赖、任意联网或宿主机 Docker 控制的脚本可能无法运行；缺少运行环境时明确报告，不绕过容器或自动安装依赖。

### 权限与打开文件

- **沙盒权限**：新对话默认使用。编码、调查、验收和已有脚本留在 Docker 中；只挂载任务源码、执行产物和过滤后的只读资料。不提供助手密钥、控制接口或 Docker Socket，执行容器默认无网络。禁止本机外部软件启动及目录外文件操作。
- **风险询问**：编码仍在 Docker 中。外部打开及明确的目录外单文件操作通过批准卡逐次批准，批准不提高模型代码权限。
- **完全权限**：本机文件操作和外部软件打开使用当前 Windows 用户权限，不逐次确认、不申请管理员权限。编码和已有脚本仍在 Docker 中，不能因为选择完全权限而改到本机执行。

权限选择在执行边界生效，刷新、暂停和恢复保留当前对话选择。界面分别显示当前有效权限、所选权限和待生效状态。模型不能切换权限或批准自己。批准绑定操作、软件、具体路径及原件状态；目标变化后须重新申请。重复点击或刷新不重复执行，结果不明时保留记录、停止自动重试。等待批准不会调用模型轮询；批准后可继续对话，程序将实际结果交给模型。

输入框工具栏依次提供工作目录、模型、思考、联网、权限和齿轮，保持单行显示。齿轮菜单仅提供 **额外可读资料** 与 **API Key 设置**。首次发送前也可建立空会话并保存权限或资料授权，不调用模型、不初始化编码任务。应用自动从 Windows 注册信息、开始菜单及商店应用中识别，无需手工登记 `.exe`；候选不唯一时由助手询问。商店应用通过 Windows 激活接口启动。

文本、代码、Markdown、HTML、常见图片和 PDF 默认在隔离预览中显示，预览内容不会自动发送给模型，授权范围内普通读取和预览无需重复批准。外部文档打开只接受文件路径和应用编号，不接受脚本、可执行文件、任意 Shell 或模型生成的启动参数。仅提供软件启动和文件打开，不提供鼠标、键盘或窗口自动操作。外部软件正常运行，其自身缓存和写入不属于沙盒保证。单文件操作不能绕过工作目录中的编码验收，也不能操作助手私有目录、凭据或系统程序目录。

Docker 初始化失败会停止执行。当前不保证所有镜像与项目依赖均兼容；配置运行环境失败后须修正配置并新建任务。执行开始后，容器内只读资料副本固定；增删执行资料须新建任务，普通查询继续按当前授权检查。

聊天流显示运行状态、耗时、退出码及助手已记录的 Token。被运行程序的模型用量与助手自身用量分开：没有可靠记录时显示“未知”。任务可通过 `usage_file` 指定本次生成的 JSON，包含非负整数 `input_tokens`、`output_tokens`、`total_tokens` 和 `cached_input_tokens`；合计必须一致，旧文件不计作本次用量。退出码 0 不等于官方验收通过。

### 补充、暂停与继续

- 运行中可以发送问题或补充要求，界面先确认已收到。
- 发送补充会主动中断正在等待或生成的模型回复，再处理新消息；不需要等待整份回复完成。
- 正在执行的单项操作完成收尾后接入补充；已经完成的操作保留，工作补充会停止旧计划中尚未开始的操作。
- 普通聊天和状态询问不会取消现有工作，工作补充才调整剩余计划。
- 点击暂停会主动中断当前模型回复；实际执行在最近的单项操作边界停下，避免文件只写一半。暂停期间聊天不会自动恢复工作。
- 刷新页面可重新连接会话；暂停后点击“继续任务”恢复。

请求或写入结果不明时，系统保留现场并停止，不自动重发，避免重复计费或重复修改。

主动中断的部分回复仅保留为本地显示记录，不作为工具交付或执行指令。中断前已经发送的模型请求可能仍产生服务费用；没有返回的用量标为未知。继续任务使用新的请求编号，不重放已经完成的操作。

### 管理对话

在左侧对话条目上右键，或点击条目右侧的菜单按钮，可归档或删除对话。归档后可在“归档”页查看和恢复；删除会移入“回收站”，仍可恢复。回收站里的“彻底删除”需要确认，会清除对话消息、思考内容及关联任务记录，无法恢复；工作仓库中的文件和独立评测记录保留。程序仅保留已删除对话的编号，防止旧页面重新创建该对话。运行中的任务须先暂停并等待当前请求或操作结束；结果不明的操作需先核对记录。

对话栏默认较窄，拖动右边缘可调整宽度；也可选中边缘后使用左右方向键，Home 恢复默认宽度。宽度保存在当前浏览器或桌面窗口的界面偏好中。

## 数据与隐私

模型请求会将本轮任务及必要材料发送到 DeepSeek。开启联网后，搜索查询交给搜索服务，网页读取请求发送到对应站点。

本机保存会话、任务记录、代码原文、执行结果及恢复进度。默认位置：

| 数据 | 位置 |
|---|---|
| 便携版任务、设置、加密密钥 | `%LOCALAPPDATA%/MonoPlanner/Data/state/` |
| 便携版会话服务数据 | `%LOCALAPPDATA%/MonoPlanner/Data/state/service/.langgraph_api/` |
| App 界面偏好与缓存 | `%LOCALAPPDATA%/MonoPlanner/WebView2/` |
| 便携版启动日志 | `%LOCALAPPDATA%/MonoPlanner/Data/launcher-logs/` |
| 历史验证与评测 | `validation/` |

可通过 `MONOPLANER_STATE_DIR` 更换任务与设置目录。密钥由 Windows 当前用户加密，不进入浏览器持久存储或模型请求归档。环境变量 `DEEPSEEK_API_KEY` 和项目 `.env` 仍可作为后备；删除本机密钥不会删除这些后备来源。

当前产品面向本机使用，默认仅监听回环地址。任务记录和 `.langgraph_api/` 是恢复所需的数据，请勿在任务进行中删除。

查询和运行记录位于任务目录的 `assistant/`，容器执行日志与状态记录位于用户数据目录的 `execution/<任务编号>/`，只读资料副本位于 `materials/<任务编号>/`；预览、批准状态和资料授权保存在本地状态目录。恢复副本位于 `file-operation-backups/<对话编号>/`，可从操作卡下载。彻底删除对话会删除其恢复副本；执行中或结果不明的外部操作阻止删除。文件读取检查授权路径、链接和敏感文件；子进程不继承服务进程的 API Key 环境变量。从源码启动仍沿用原默认数据目录和启动日志位置，不迁移旧任务。

## 常见问题

**双击后没有打开界面。** 便携版查看 `%LOCALAPPDATA%/MonoPlanner/Data/launcher-logs/latest.json` 和相应日志，确认完整解压、2024 和 3000 端口没有被其他程序占用。从源码启动的日志在 `validation/launcher-logs/`。

**怎样更新？** 便携版先暂停并退出 App，再将新包解压到新目录；不要覆盖运行中的文件。用户数据保留在用户目录。旧任务使用对应的冻结源码恢复，新包不会迁移旧检查点。从源码更新前端时才需要重新构建。

**普通聊天必须先选目录吗？** 不需要。实际源码工作才需要选择目录。

**为什么暂停后不能自动继续？** 如果请求或执行结果不明，需要先核对现场。旧任务也必须使用对应的冻结版本恢复，不能用新代码静默迁移。

**思考是否实时显示？** 工作界面分段接收思考内容，展开后随生成追加显示。显示片段追加到 `display/model.jsonl`，显示写入或读取失败只影响展示；完整请求、响应和检查点仍须可靠保存。完成后用完整响应恢复显示。思考和操作默认两层折叠，公开回复及用户消息保持可见。工具参数须完整接收并校验后才执行；流式中断会保留已有记录并停止，不自动重发。设置或活动读取失败时可点击重新连接，只重试查询。思考的模型续接规则保持不变，展示不会新增模型调用。
